## Why

Репозиторий пуст, а все следующие изменения (доска, симулятор, плеер уроков, вход, выкатка) опираются на общий каркас: структуру проекта, маршруты, сервер и инструменты проверки. Мультиязычность (украинский, русский, английский, литовский) закладывается сейчас: встроить её позже значит переписать каждый экран и формат контента. Проект открытый: сторонние разработчики должны запускать его у себя одной командой и добавлять уроки, не трогая общий код.

## What Changes

- pnpm-workspace из двух приложений: `apps/web` (Foldkit SPA на Effect) и `apps/server` (Node + Effect: раздаёт сборку web и `/api`). Версии пинуются точно: `effect@4.1.0`, `@effect/platform-node@4.1.0`, `@effect/platform-browser@4.1.0`, `foldkit@0.169.0`. Foldkit официально заявляет `effect@4.0.0`, поэтому 4.1.0 навязывается через `pnpm.overrides`, а совместимость проверяется первым шагом.
- Каркас web-приложения:
  - шапка с переключателем языка;
  - главная — карта курса из 13 уроков с названиями и описаниями на выбранном языке;
  - заготовка страницы урока с тремя зонами: теория, доска, приборы;
  - страница «не найдено».
  - Светлая и тёмная темы на токенах из макета `docs/mockups/lesson-load-balancer.html`, свои шрифты с кириллицей и литовской латиницей.
- Локализация с первого дня:
  - языки `uk`, `ru`, `en`, `lt` как префикс URL;
  - выбор языка при первом входе, переключение без перезагрузки, запоминание выбора;
  - атрибут `lang` документа;
  - типизированные словари интерфейса с проверкой полноты;
  - правила множественного числа и формат чисел для каждого языка;
  - контракт «доменная логика возвращает коды, тексты собирает слой локализации».
- Сервер: раздача сборки с fallback на SPA для языковых маршрутов, `/api/health`, JSON 404 для неизвестных `/api/*`, настройка из переменных окружения, корректная остановка по SIGTERM.
- Инструменты: TypeScript strict, vitest (Story/Scene для Foldkit, node-тесты для сервера), oxlint с плагином Foldkit, oxfmt; одна команда `pnpm check` (типы, линтер, тесты) и `pnpm build`.
- Открытый проект:
  - уроки — самостоятельные модули-папки с автоматическим реестром, новый урок не требует правок в общем коде;
  - урок объявляет свои языки, а на остальных показывается на английском с пометкой;
  - `pnpm install && pnpm dev` работает без `.env` и внешних сервисов.
- Документы: `README.md` с быстрым стартом, `CONTRIBUTING.md` (как прислать урок), `LICENSE`, `AGENTS.md` с правилами проекта, `FOLDKIT.md` из шаблона.

## Capabilities

### New Capabilities

- `app-shell`: каркас приложения — главная с картой курса, заготовка страницы урока, страница «не найдено», заголовок документа, темы, адаптивность.
- `localization`: поддерживаемые языки, выбор и переключение языка, запоминание, полнота переводов, множественное число и числа, локализация доменных сообщений и контента.
- `web-server`: HTTP-сервер приложения — раздача web-сборки, служебные API-ответы, конфигурация и жизненный цикл процесса.
