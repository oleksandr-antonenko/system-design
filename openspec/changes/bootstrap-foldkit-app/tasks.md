## 2. Ядро локализации (`apps/web/src/i18n`)

- [x] 2.1 `locale.ts`: Schema `Locale` (`uk`, `ru`, `en`, `lt`), самоназвания языков, чистая `resolveLocale({ savedLocale, browserLanguages })`. Проверка: табличный тест покрывает сценарии «сохранённый важнее браузера», «язык браузера», «неподдерживаемый → en» и «повреждённое значение».
- [x] 2.2 `plural.ts` и `format.ts`: множественное число на `Intl.PluralRules` с формами, типизированными по языку, и форматирование чисел на кешированных `Intl.NumberFormat`. Проверка: тест на 0, 1, 2, 3, 5, 10, 11, 21, 22 и 1.5 для всех языков (пример «урок/урока/уроков», «pamoka/pamokos/pamokų») и на 12500.
- [x] 2.3 `ui/types.ts` и словари `ui/{uk,ru,en,lt}.ts` через `satisfies UiStrings`: шапка, переключатель, карта курса, зоны урока, «не найдено», «скоро», служебный доменный код из design D6. Проверка: удаление ключа из `lt.ts` даёт ошибку tsc (проверено вручную и откатено), тест непустых строк проходит.
- [x] 2.4 Механизм доменных сообщений (D6): тип кода с параметрами и функция отображения, полнота которой проверяется типом. Проверка: тест показывает, что одно и то же сообщение рендерится на всех четырёх языках с одинаковыми параметрами.
- [x] 2.5 Уроки как модули (design D7): 13 папок `lessons/<NN>-<slug>/` с `meta.ts` (место в курсе, `available`, объявленные языки) и `text.{uk,ru,en,lt}.ts` (название, описание). Реестр через `import.meta.glob`, тест уникальности `slug` и порядка. Проверка: тест полноты падает с названием урока и языка, если убрать перевод объявленного языка; новая папка появляется на карте курса без правок в других файлах.
- [x] 2.6 Запасной язык урока: функция выбора текста урока (язык страницы → `en` → первый объявленный) и пометка «не переведён». Проверка: тест на урок, написанный только на `en` и `ru` и открытый на `lt`.

- [ ] 4.3 Корректная остановка по SIGTERM. Проверка: тест запускает сервер дочерним процессом, отправляет медленный запрос и SIGTERM; запрос завершается полностью, код выхода 0.
- [ ] 4.4 Dev-связка: прокси Vite `/api` → сервер, `pnpm dev` поднимает оба процесса. Проверка: на `http://localhost:5173/api/health` приходит ответ сервера.
- [ ] 4.5 Запуск без настройки (design D7a): значения по умолчанию для разработки, SQLite-каталог в `.gitignore`, секреты обязательны только в production. Проверка: свежий `git clone` во временный каталог, `pnpm install && pnpm dev` без `.env` открывает приложение, `/api/health` отвечает 200.
