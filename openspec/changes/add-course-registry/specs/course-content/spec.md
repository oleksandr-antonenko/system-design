## MODIFIED Requirements

### Requirement: Все уроки программы доступны

Программа курса System Design SHALL состоять из 13 уроков, и каждый из них MUST открываться как урок с шагами, доской и задачей. Пунктов программы System Design без содержания MUST NOT оставаться. Заглушки «скоро» допустимы только в курсах, которые ещё пишутся.

#### Scenario: Оглавление

- **WHEN** ученик открывает программу курса System Design
- **THEN** все 13 уроков — ссылки, и каждая ведёт на урок с шагами и доской
