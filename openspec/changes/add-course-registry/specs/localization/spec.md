## MODIFIED Requirements

### Requirement: Выбор языка при первом входе

Для адреса без языкового префикса приложение SHALL выбрать язык по порядку: сохранённый выбор пользователя, затем первый из языков браузера, чей основной подтег поддерживается, иначе `en`. После выбора приложение MUST перенаправить на тот же путь с префиксом выбранного языка, заменив запись в истории, чтобы кнопка «Назад» не возвращала на адрес без префикса.

#### Scenario: Сохранённый выбор важнее браузера

- **WHEN** сохранён язык `lt`, браузер сообщает `uk-UA`, и ученик открывает `/`
- **THEN** открывается `/lt/`

#### Scenario: Язык браузера

- **WHEN** сохранённого выбора нет, браузер сообщает `["uk-UA", "en-US"]`, и ученик открывает `/`
- **THEN** открывается `/uk/`

#### Scenario: Неподдерживаемый язык браузера

- **WHEN** сохранённого выбора нет, браузер сообщает `["de-DE"]`, и ученик открывает `/`
- **THEN** открывается `/en/`

#### Scenario: Ссылка без префикса

- **WHEN** ученику с сохранённым языком `ru` открывают `/networks/`
- **THEN** открывается `/ru/networks/`, а «Назад» не возвращает на `/networks/`

#### Scenario: Старая ссылка на урок без префикса

- **WHEN** ученику с сохранённым языком `ru` открывают `/lessons/load-balancer`
- **THEN** открывается `/ru/system-design/lessons/load-balancer`, а «Назад» не возвращает на `/lessons/load-balancer`

### Requirement: Переключение языка

На каждой странице SHALL быть переключатель языка. Он показывает названия языков на них самих: «Українська», «Русский», «English», «Lietuvių». Переключение MUST открывать ту же страницу с префиксом выбранного языка без перезагрузки, сохранять остальную часть адреса, обновлять атрибут `lang` документа и заголовок вкладки. Каждый пункт переключателя MUST быть обычной ссылкой, которую можно открыть в новой вкладке.

#### Scenario: Смена языка на странице урока

- **WHEN** ученик на `/ru/system-design/lessons/load-balancer` выбирает «English»
- **THEN** открывается `/en/system-design/lessons/load-balancer` с английскими текстами, а атрибут `lang` документа равен `en`
