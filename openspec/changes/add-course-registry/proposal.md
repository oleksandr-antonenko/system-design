## Why

На сайте появляется второй курс, «Сети для вайбкодеров» (план `docs/plans/networks-course.md`, разделы 4.1 и 3.4). Сейчас платформа знает только один курс: уроки лежат в общей папке, модули и название курса зашиты в словари интерфейса, адреса не содержат курса. Это изменение — пункт 1 раздела 4.6 плана: без него нельзя добавить ни один урок второго курса.

## What Changes

- **Курс — модуль.** Папка `apps/web/src/courses/<курс>/`: описание курса (`course.ts`: id, вид доски, модули, языки, набор элементов интерфейса), тексты курса на каждом языке (`course.<язык>.ts`: название, слоган, названия модулей) и уроки (`lessons/NN-slug/`). Реестр собирает курсы и уроки сам и проверяет их.
- **13 уроков System Design** переезжают в `courses/system-design/lessons/` без изменения содержания.
- **Маршруты:**
  - `/:язык/` — каталог курсов;
  - `/:язык/:курс/` — карта курса;
  - `/:язык/:курс/lessons/:slug?step=N` — урок;
  - **BREAKING для ссылок:** старые адреса `/:язык/lessons/:slug` перенаправляются на `/:язык/system-design/lessons/:slug` с тем же шагом.
- **Шапка:** логотип ведёт в каталог, рядом переключатель курса.
- **Курс `networks` виден:** 16 уроков-заглушек «скоро» по программе плана (раздел 2), названия и описания на uk, ru, en, lt.
- **Интерфейс растёт вместе с учеником:**
  - урок объявляет, какие элементы интерфейса он открывает (`unlocks`);
  - открыто всё, что открыли уроки курса до текущего включительно;
  - для `networks` полный набор элементов заведён сразу по таблице 3.4, заглушки заполнены.
- **Палитра «Позже в курсе»** считается в пределах своего курса.

## Capabilities

### New Capabilities

- `course-registry`: курсы как модули, проверка курсов и их уроков, каталог курсов, переключатель курса, курс «Сети для вайбкодеров» в программе, открытие элементов интерфейса по урокам.

### Modified Capabilities

- `app-shell`: карта курса переезжает на `/:язык/:курс/`, урок — на `/:язык/:курс/lessons/:slug`, старые адреса перенаправляются, шапка получает каталог и переключатель курса.
- `lesson-player`: ссылка на шаг содержит курс.
- `localization`: примеры адресов в сценариях выбора и переключения языка содержат курс.
- `system-board`: «Позже в курсе» считается по урокам своего курса.
- `course-content`: требование «все уроки доступны» относится к курсу System Design.

## Impact

- **Код `apps/web`:** новая папка `src/courses/` вместо `src/lessons/`, маршруты, корневые `main.ts` и `view.ts`, плеер (знает курс урока), четыре словаря интерфейса. Название курса, слоган и модули System Design уходят из словарей в тексты курса.
- **Сервер:** без изменений, он отдаёт приложение на любой путь. Тест сервера получает адрес нового вида.
- **CI:** проверка после выкатки опрашивает только `/api/health`, адресов уроков в ней нет.
- **Документация:** `AGENTS.md`, `CONTRIBUTING.md`, `apps/web/AGENTS.md`, `openspec/config.yaml` — новый путь урока и модули курсов.
- **Следующие изменения плана** (`add-quiz-steps`, `extract-board-kind`, `add-network-board` и другие) пользуются контрактом курса и `unlocks` из этого изменения.
