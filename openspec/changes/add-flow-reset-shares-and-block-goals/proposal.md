## Why

Уроки System Design растут из одной схемы в одну задачу. Авторам новых уроков нужны три вещи, которых у движка `flow` пока нет:

- **Поэтапные уроки.** Урок из нескольких этапов строит каждый следующий этап на общей эталонной схеме, а не на схеме ученика: иначе текст и задачи следующего этапа не совпадут с доской у разных учеников. У доски сетей для этого уже есть `NetOp.Reset`, у доски потоков — нет.
- **Неравные группы пользователей.** Сейчас нагрузка делится поровну между всеми блоками «Users». Реальная система обслуживает регионы и группы разного размера: три четверти трафика из одного региона, четверть из другого.
- **Цели про конкретный блок.** `MaxUtilization` и `MaxBacklog` проверяют все блоки вида или всю систему, а цель «этот блок держит нагрузку» выполняется и пустым блоком, через который ничего не идёт.

## What Changes

- **`BoardOp.Reset`** возвращает доску к `emptyBoard`. DSL `reset()`, строка журнала `Reset`. Шаг пишет `ops: [reset(), ...reference, ...twist]`; на прежнем шаге ученик по-прежнему видит свою схему.
- **`BoardOp.SetShare({ id, share })`** и поле `shares` в `BoardDoc`: вес группы пользователей, по умолчанию 1. Симуляция даёт группе `load × share / Σshares`. Цели с `load` масштабируют все группы пропорционально. DSL `setShare(id, share)`, строка журнала `SetShare <id> · <share>`. Отказы: доля не у блока «Users» (`ShareNotForUsers`), доля не больше нуля или не число (`InvalidShare`).
- **`MaxUtilization` и `MaxBacklog`** получают необязательное поле `nodes` (id блоков): цель проверяет только перечисленные блоки.
- **Новая цель `Carries({ node, min, load })`**: через блок проходит не меньше `min` rps. Проверяется прогоном нагрузки, до проверки скрыта. Невыполненная цель называет блок, нагрузку, поток и порог (`GoalNotCarrying`) на uk, ru, en, lt.
- **Снимки симулятора** по 13 урокам System Design (`courses/system-design/simulation.test.ts`): метрики каждого шага, доски задачи до и после эталона, итоги целей, числа в текстах на четырёх языках. Снимки сделаны до изменения движка и подтверждают, что уроки 1–13 считаются как раньше.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `lesson-player`: шаг может начать доску заново (`reset()`).
- `traffic-simulation`: группы пользователей делят нагрузку по весам.
- `task-checking`: цели загрузки и очереди по выбранным блокам, цель «через блок проходит поток».

## Impact

- **Код:** `apps/web/src/domain/board.ts` (`shares`, `SetShare`, `Reset`, `shareOf`), `domain/simulate.ts` (деление нагрузки), `domain/goals.ts` (`nodes`, `Carries`), `kinds/flow/dsl.ts` (`setShare`, `reset`), `kinds/flow/kind.ts` (журнал), `lesson/ghost.ts`, `i18n/domainMessage.ts` и словари uk, ru, en, lt (три новых сообщения).
- **Уроки 1–13** не меняются: без `SetShare` веса равны 1, без `nodes` цели проверяют всё, как раньше. Снимки и тесты контента это проверяют.
- **Документация:** `CONTRIBUTING.md` — операции `setShare`, `reset` и цели `Carries`, `nodes`.
- **Зависимости:** без новых.
