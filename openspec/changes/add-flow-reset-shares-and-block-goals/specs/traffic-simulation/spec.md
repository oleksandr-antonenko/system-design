## ADDED Requirements

### Requirement: Доли групп пользователей

Блоки «Users» SHALL делить общую нагрузку по весам: группа получает `load × share / Σshares`, где сумма — по всем блокам «Users» на доске. Вес группы по умолчанию равен 1, поэтому без `setShare` группы делят нагрузку поровну и числа совпадают с прежними. Вес задаёт операция `setShare(id, share)`; он MUST быть конечным числом больше нуля и относиться к блоку «Users», иначе операция отклоняется с пояснением на языке страницы. Цели с нагрузкой SHALL масштабировать все группы пропорционально их весам. Удаление группы убирает её вес.

#### Scenario: Три четверти нагрузки из одного региона

- **WHEN** на доске `users-eu` с весом 1 и `users-us` с весом 3, а нагрузка 400 rps
- **THEN** `users-us` отправляет 300 rps, а `users-eu` — 100 rps

#### Scenario: Цель с другой нагрузкой

- **WHEN** та же доска проверяется целью с нагрузкой 800 rps
- **THEN** `users-us` отправляет 600 rps, а `users-eu` — 200 rps

#### Scenario: Уроки без долей

- **WHEN** урок не задаёт долей групп
- **THEN** каждая из групп получает одинаковую долю нагрузки, и метрики уроков 1–13 совпадают со снимками до изменения

#### Scenario: Доля не для пользователей

- **WHEN** автор задаёт долю блоку `app1`
- **THEN** операция отклоняется с пояснением, что долю задают только блоку «Users»
