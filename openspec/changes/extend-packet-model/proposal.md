## Why

Модель пакетов (`packet-network`, архив `add-packet-model`) покрывает только MVP, а её тесты-сценарии идут по старой нумерации уроков. Курс «Сети для вайбкодеров» пересобран для новичков: 16 уроков, модуль 1 стал мягче (план `docs/plans/networks-course.md`, «Пересмотр после первого макета» и раздел 2). Владелец попросил собрать весь курс, поэтому модели нужно сразу всё, на чём стоят уроки 1–16, а поверхностям (доска, терминал, браузер, панель настроек) — общий чистый контракт, по которому их строят параллельно.

## What Changes

- **Тексты кодов `NetMessage`** на uk, ru, en, lt: отдельный модуль рядом с моделью, полнота проверяется типами и тестом. Слова простые, пакет в текстах — «конверт».
- **Мир сети:** документ и состояние сворачиваются одной цепочкой операций. Новые операции: отправить намерение (`Send`), подождать (`Wait`, логические часы), выполнить команду терминала (`RunCommand`), выпустить сертификат (`IssueCertificate`).
- **Терминал:** чистый интерпретатор команд с упрощённым выводом в стиле Unix (`ip a`/`ipconfig`, `ping`, `arp -a`, `npm run dev`, `traceroute`, `nslookup`, `dig`, `curl -v`, `ss -ltn`, `docker`, `ufw`, `certbot`). Незнакомая или ещё закрытая команда даёт подсказку-код, а не ошибку шелла.
- **Браузер:** чистая функция «открыть адрес» → страница или настоящий код ошибки браузера плюс трасса для анимации.
- **Механика В2 (уроки 8–11):** транзитные роутеры провайдера и цепочка в интернете, роутер за роутером, статические маршруты и таблица маршрутов, ICMP Time Exceeded и traceroute, видимая таблица NAT, проброс портов, CGNAT, сводка пула DHCP, записи DNS A/AAAA/CNAME/MX/TXT/NS с TTL, рекурсивный резолвер и кэши на логических часах, проверки сертификата TLS таблицей правил, перенаправление HTTP→HTTPS, ACME HTTP-01, адрес клиента глазами сервера.
- **Механика В3 (уроки 12–16):** файрвол (ОС, роутер, облачная security group; входящие и исходящие; allow, drop, reject; сработавшее правило на хопе), VPN (инкапсуляция, full и split tunnel, DNS через VPN), хост Docker (сеть bridge и compose, `-p`, имена сервисов, `localhost` внутри контейнера, `host.docker.internal`, публикация порта мимо файрвола ОС), ретранслятор туннеля, mesh-сеть, мобильная сеть телефона, приложение с зависимостью (сервер → база).
- **Wi-Fi для поверхностей:** сети рядом с уровнем сигнала, проверка подключения с понятной причиной, стены, которые сокращают дальность.
- **Новые цели:** `ValidCert`, `OnlyOpenPorts`, `WifiSecurity`, `ChannelClear`, `RanCommand`, `HasRecord`.
- **Тесты-сценарии по сюжетам всех 16 уроков** нового плана; старые сценарии перенесены под новую нумерацию.
- **BREAKING (только внутри `net/`):** `Intent.Ping` принимает `host` (адрес или имя) вместо `ip`; записи DNS получили тип и TTL; кэш DNS — тип, значение и срок; у хопа появилось сработавшее правило файрвола. Внешних потребителей модели пока нет.

## Capabilities

### New Capabilities

Нет: всё расширяет `packet-network`.

### Modified Capabilities

- `packet-network`: документ и операции, Wi-Fi, шлюз и NAT, DNS, трасса намерения и цели расширяются; добавляются мир сети и логические часы, маршрутизация и traceroute, проброс портов и CGNAT, рекурсивный DNS, TLS и ACME, файрвол, VPN, Docker, туннель, mesh, терминал, браузер и тексты сообщений.

## Impact

- **Код:** `apps/web/src/net/` (изменённые и новые модули) и `apps/web/src/net/text/` (тексты). Плеер, доска, маршруты, реестр уроков и общие словари `apps/web/src/i18n/ui/*` не меняются; модуль текстов только импортирует тип `Locale`.
- **Зависимости:** прежние — `effect` 4.1 и `defineTaggedUnion` из `foldkit/schema`.
- **Следующие изменения** плана (4.6: доска `packet`, терминал и браузер, панель настроек, уроки трёх модулей) получают готовый контракт: операции и конструкторы `build.ts`, намерения, цели, `runCommand`, `browse`, тексты. Пункты 9 и 11 плана (`extend-packet-model-internet`, `extend-packet-model-dev`) этим изменением закрыты по части модели.
