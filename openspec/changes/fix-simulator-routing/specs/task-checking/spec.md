## ADDED Requirements

### Requirement: Цель по доле отказов

Цель `MaxRejectedRate({ max, load })` SHALL выполняться, когда при нагрузке `load` доля запросов, отклонённых ограничителями (429), не выше `max`. Невыполненная цель MUST подсвечивать ограничители, которые отклоняют, и называть долю. Цель `MaxErrorRate` MUST NOT учитывать отказы 429.

#### Scenario: Ограничитель режет слишком много

- **WHEN** 2000 rps идут через один ограничитель на 1000, а цель `MaxRejectedRate({ max: 0.2, load: 2000 })`
- **THEN** цель не выполнена, подсвечен ограничитель, сообщение называет 50 %
