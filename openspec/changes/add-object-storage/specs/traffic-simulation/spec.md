## ADDED Requirements

### Requirement: Object storage в потоке

Object storage SHALL держать до 50 000 rps и стоить 0,05 $ в час. Сверх ёмкости хранилище теряет запросы; потерянные запросы пользователей считаются ошибками. Хранилище — конец потока: дальше оно ничего не передаёт.

Запросы пользователей, которые дошли до хранилища напрямую (загрузка по presigned URL) или промахами CDN, SHALL входить во время ответа: путь до хранилища, включая переходы между регионами, плюс 40 мс. Worker SHALL класть в каждое своё живое хранилище по одному объекту на обработанную задачу, отдельно от записей в базы; эти объекты MUST NOT считаться запросами пользователей.

#### Scenario: Прямая загрузка

- **WHEN** пользователи отправляют 1000 rps прямо в хранилище
- **THEN** ошибок нет, хранилище загружено на 2 %, а p95 — 40 мс

#### Scenario: Загрузка из другого региона

- **WHEN** пользователи из `eu` загружают файлы в хранилище в регионе `us`
- **THEN** p95 — 110 мс: 40 мс хранилища и 70 мс перехода между регионами

#### Scenario: Промахи CDN в p95

- **WHEN** 1000 rps идут через CDN, которая отдаёт сама 60 % и берёт остальное из хранилища
- **THEN** хранилище получает 400 rps, а p95 — 40 мс; при 97 % статики p95 — 12 мс

#### Scenario: Результаты worker

- **WHEN** worker обрабатывает 100 задач в секунду, связан с базой и хранилищем, а `writesPerJob` равен 2
- **THEN** он пишет в базу 200 rps и кладёт в хранилище 100 объектов в секунду, ошибок пользователей нет

#### Scenario: Перегруженное хранилище

- **WHEN** 1500 rps идут прямо в хранилище с ёмкостью 1000
- **THEN** теряется треть запросов, и хранилище названо среди блоков, которые теряют запросы
