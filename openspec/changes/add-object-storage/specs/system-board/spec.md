## ADDED Requirements

### Requirement: Object storage на доске

Доска SHALL рисовать блок Object storage так же, как остальные: своя иконка, подпись «Object storage» на любом языке страницы, полоска загрузки и родное объяснение в подсказке палитры и описании блока. Новые блоки этого вида SHALL получать имена `storage-1`, `storage-2` и так далее, а добавленный кликом или с клавиатуры блок встаёт в правую колонку доски. Допустимы связи `Users → Object storage`, `CDN → Object storage` и `Worker → Object storage`; любая другая связь с хранилищем MUST отклоняться с пояснением на языке страницы, а из хранилища связь MUST NOT начинаться.

#### Scenario: Хранилище из палитры

- **WHEN** ученик на пустой доске нажимает «Object storage» в палитре
- **THEN** в правой колонке доски появляется блок `storage-1`

#### Scenario: Сервер не пишет в хранилище напрямую

- **WHEN** ученик тянет связь от `app1` к `storage-1`
- **THEN** связь не создаётся, а пояснение перечисляет, куда сервер может передавать запросы

#### Scenario: Объяснение на русском

- **WHEN** на странице `/ru/...` ученик наводит указатель на «Object storage» в палитре
- **THEN** подсказка начинается с «Объектное хранилище:» и объясняет, что оно хранит файлы и отдаёт их по ссылке
