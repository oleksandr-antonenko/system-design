## Why

Ученикам нужен аккаунт, чтобы прогресс по курсу не терялся при смене устройства или очистке браузера. Вход должен быть привычным: почта с паролем или Google. Конфигурация better-auth уже проверена в других проектах владельца, её стоит перенести на наш стек: Effect-сервер плюс Foldkit-клиент.

## What Changes

- Сервер: better-auth 1.7 на `/api/auth/*` через мост между Effect HTTP и web Request/Response.
  - Почта и пароль с открытой регистрацией и обязательным подтверждением почты.
  - Сброс пароля с автоматическим входом после задания нового.
  - Google включается сам, если на сервере заданы `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET`.
  - Автоматическая привязка Google к аккаунту с той же подтверждённой почтой.
  - Лимит попыток по `X-Forwarded-For`.
- Хранилище: SQLite `data/app.db` (Drizzle + better-sqlite3). Миграции применяются при старте, с защитой от каскадного удаления таблиц сессий.
- Почта: SMTP с ленивым созданием транспорта, письма на языке пользователя (uk, ru, en, lt). Без SMTP письма пишутся в журнал (разработка), а регистрация по почте в проде скрыта, чтобы не появлялись аккаунты, которые нельзя подтвердить.
- Web (Foldkit), все тексты на четырёх языках:
  - страницы `/{язык}/sign-in`, `/sign-up`, `/forgot-password`, `/reset-password`, `/account`;
  - состояние входа в Model (загружается при старте);
  - меню аккаунта в шапке;
  - коды ошибок better-auth переводятся в понятные сообщения через механизм доменных кодов.
- Язык аккаунта: сохраняется при регистрации, меняется переключателем и используется для писем.
- Удаление аккаунта со всеми данными (требование GDPR, курс доступен и в Литве).
- Курс остаётся полностью доступен без входа, но прогресс сохраняется только у вошедших. Сохранение прогресса в аккаунт появится вместе с плеером уроков (изменение `add-learning-progress` в `docs/roadmap.md`).
- Локальная разработка без настройки: без `.env` используется секрет разработки, письма печатаются в консоль, Google выключен.

## Capabilities

### New Capabilities

- `user-accounts`: регистрация, подтверждение почты, вход по паролю и через Google, сброс пароля, выход, состояние входа в интерфейсе, язык аккаунта, удаление аккаунта, безопасность сессий.

### Modified Capabilities

(нет — `localization` и `web-server` ещё не перенесены в основные спецификации. Новые тексты подчиняются требованию полноты переводов из `localization`.)

## Impact

- Сервер: новые зависимости `better-auth@1.7.14`, `drizzle-orm`, `drizzle-kit`, `better-sqlite3`, `nodemailer`. Сервисы Effect `Database`, `Mailer`, `Auth`, маршрут `/api/auth/*` и служебные `/api/account/*`.
- Web: новые маршруты и страницы, состояние сессии в корневом Model, меню в шапке, около 60 новых строк интерфейса на каждом из четырёх языков.
- Выкатка: новые переменные в `.env` на сервере (`BETTER_AUTH_SECRET`, `BETTER_AUTH_URL`, `DATABASE_PATH`, `SMTP_URL`, `MAIL_FROM`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`), база попадает в резервные копии `release.sh`.
- Владельцу: создать OAuth-клиент в Google Cloud Console и выбрать почтовый ящик-отправитель.
- Зависит от `bootstrap-foldkit-app` и `setup-deploy-pipeline`.
