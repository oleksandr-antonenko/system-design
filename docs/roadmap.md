# Дорожная карта

Архитектура — гибрид трёх планов из `docs/plans/`:

- **Урок как сценарий (план B).** Демонстрации автора и ходы ученика записываются одним языком операций `BoardOp`. Доска на шаге N получается применением операций шагов 0..N.
- **Симулятор потоков (план A).** Фиксированный шаг, детерминированный, чистая функция.
- **Идеи плана C — на поздние фазы:** «предскажи, что будет», реплики по времени симуляции, подсветка узкого места, итоговый проект на SLO.

Макет урока: `docs/mockups/lesson-load-balancer.html`.

Проект открытый:

- репозиторий публичный;
- `pnpm install && pnpm dev` работает без настройки;
- уроки — самостоятельные модули, которые присылают через PR;
- приложение — статическая SPA: сборку `apps/web` раздаёт любой статический хостинг.

Каждый пункт — отдельное изменение OpenSpec (`openspec/changes/<имя>`). Порядок отражает зависимости.

### Прогресс

- **Не сохраняется.** Курс доступен полностью, но после закрытия вкладки ученик начинает урок заново.
- **Ссылка на конкретный шаг** (`/uk/<курс>/lessons/<урок>?step=N`) работает у всех. Это адрес, а не сохранённый прогресс.

План — [docs/plans/networks-course.md](plans/networks-course.md). Курс живёт на том же сайте со своим адресом, квиз можно пропустить после первой попытки. Первым идёт `add-packet-model` (модель пакетов, новые файлы), затем реестр курсов, квизы и вторая доска.

## Третий курс: «Кибербезопасность для офиса»

План — [docs/plans/security-course.md](plans/security-course.md), демо — `docs/mockups/security-lesson-1.html` и `security-lesson-2.html`. Изменение `add-security-course`: вид доски `scenario` (кадры мультика и экраны телефона, почты и страницы-двойника), уроки-слайды, которые листает только ученик, программа из 12 уроков и первые два урока — 1 «Wi-Fi. Общая комната» и 5 «Phishing. Письмо-приманка». Остальные уроки MVP (2, 4, 6, 10, 11) собраны на новых экранах вида (менеджер паролей, 2FA, мессенджер, ИИ-ассистент и токены CRM, почта с пересылкой в IT и сеансами); их кадры сгенерированы моделью Gemini по листу персонажей, промпты — в `frames.md` каждого урока. Дальше — волна В2. Курс бесплатный и открыт всем.

## Решения владельца

- Effect 4.1.0, хотя Foldkit 0.169 официально заявляет 4.0.0.
- Четыре языка: uk, ru, en, lt. Урок можно прислать на одном языке, на остальных он показывается на английском с пометкой.
- Элементы системы в курсе System Design везде называются по-английски (Load balancer, Database, Read replica…), в том числе на доске; каждый термин один раз объясняется на языке ученика (`english-system-terms`).
- Публичный репозиторий, уроки от сообщества через PR.
- Приложение — статическая SPA без настройки и внешних сервисов.
- Хостинг на домашнем сервере владельца.
