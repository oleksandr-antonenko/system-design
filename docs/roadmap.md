# Дорожная карта

Архитектура — гибрид трёх планов из `docs/plans/`:

- **Урок как сценарий (план B).** Демонстрации автора и ходы ученика записываются одним языком операций `BoardOp`. Доска на шаге N получается применением операций шагов 0..N.
- **Симулятор потоков (план A).** Фиксированный шаг, детерминированный, чистая функция.
- **Идеи плана C — на поздние фазы:** «предскажи, что будет», реплики по времени симуляции, подсветка узкого места, итоговый проект на SLO.

Макет урока: `docs/mockups/lesson-load-balancer.html`.

Проект открытый:

- репозиторий публичный;
- `pnpm install && pnpm dev` работает без настройки;
- уроки — самостоятельные модули, которые присылают через PR;
- версия на `system-design.oleksandr-antonenko.com` дополнительно даёт вход и сохранение прогресса.

Каждый пункт — отдельное изменение OpenSpec (`openspec/changes/<имя>`). Порядок отражает зависимости.

### Прогресс

- **Сохраняется только у вошедших.** Прогресс лежит в аккаунте: вошёл на любом устройстве и продолжил с того же урока и шага.
- **У гостя ничего не запоминается.** Курс доступен полностью, но после закрытия вкладки прогресс не сохраняется. На странице урока есть ненавязчивая подсказка «войдите, чтобы сохранять прогресс», без блокирующих окон.
- **Ссылка на конкретный шаг** (`/uk/lessons/<урок>?step=N`) работает у всех. Это адрес, а не сохранённый прогресс.

## Решения владельца

- Effect 4.1.0, хотя Foldkit 0.169 официально заявляет 4.0.0.
- Четыре языка: uk, ru, en, lt. Урок можно прислать на одном языке, на остальных он показывается на английском с пометкой.
- Публичный репозиторий, уроки от сообщества через PR.
- Хостинг на домашнем сервере, вход через better-auth с Google.
- Прогресс сохраняется только у вошедших пользователей, у гостей ничего не запоминается.
