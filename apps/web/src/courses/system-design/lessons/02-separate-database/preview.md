# Preview: Separate database

<!-- Subject of the preview image. The shared prompt and the style: docs/plans/lesson-previews.md -->

Two separate machines side by side with clear space between them. On the left, a slim application server whose open front shows empty, clean slots: it keeps no data of its own (stateless). On the right, on its own raised platform, a database drawn as a stack of three thick cylinders. One bright accent link carries a steady stream of small data packets between the server and the database. Request pulses arrive at the server from client devices on the far left.
