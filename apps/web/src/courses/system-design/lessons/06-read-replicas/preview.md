# Preview: Read replicas

<!-- Subject of the preview image. The shared prompt and the style: docs/plans/lesson-previews.md -->

One primary database (a stack of cylinders, slightly larger) in the centre-left receives write arrows from a server on the far left. From the primary, three dashed accent replication lines, slightly delayed pulses on them, run to three smaller read replica cylinder stacks arranged in an arc on the right. Many read request paths from the server go directly to the replicas, while only the write path goes to the primary.
