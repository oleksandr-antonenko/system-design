# Preview: Rate limiter

<!-- Subject of the preview image. The shared prompt and the style: docs/plans/lesson-previews.md -->

A dense, chaotic flood of request pulses arrives from the left at a gate module: a rate limiter shaped like a narrow sluice or valve. Many excess pulses are deflected at the gate and bounce back to the left as short muted red sparks. Through the gate passes only an even, regulated stream of accent pulses, flowing on to a load balancer and two server units on the right, which run calmly without overload.
