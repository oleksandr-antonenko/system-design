# Preview: Single server

<!-- Subject of the preview image. The shared prompt and the style: docs/plans/lesson-previews.md -->

A single server unit stands alone on a small raised platform in the centre. From the left, many thin streams of glowing request pulses arrive from a loose row of small client devices (laptops and phones seen as simple dark slabs). All the streams converge on this one server; it is visibly at its limit: its status lights burn bright and one small light turns muted red. Apart from the small client devices, this server is the only machine in the whole picture: no other boxes, nodes or modules anywhere, nothing behind it, which makes it feel exposed: a single point of failure. Empty space around it.
