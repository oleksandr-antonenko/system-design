# Preview: NAT

Several home devices (a laptop, a phone, a game console shaped as a plain box, a desktop computer) on the left all send their paths into one home router. From the router, only a single thick accent path, one public address, leaves to the internet on the right, drawn as a cluster of linked network nodes (not a globe). Beside the router floats an abstract translation table of blank rows. A second, clearly separate path comes in from the internet, passes through the router and ends at exactly one computer, which glows: port forwarding.
